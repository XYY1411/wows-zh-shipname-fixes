# 翻译修正流程

## 键值格式

- `IDS_P?S????`（系别/舰种）、`IDS_P?S????_FULL`（完整舰名）
- `IDS_PCZ...` 属收集品，不算舰船词条

## 人工翻译

1. 打开 `translations/<版本号>/ship.xlsm`，启用宏
2. 在 **E 列「最终翻译」** 填修正译名，保存提交
3. 新版本同步后自动迁移旧版本已填翻译，只需填新增舰船

## 配色规则（宏）

| 位置 | 规则 | 颜色 |
|---|---|---|
| E 列 | 空值 | 亮红 |
| E 列 | B=C=D=E | 浅红 |
| E 列 | B=C 且 E=B | 白 |
| E 列 | E=B 且 B≠C | 浅蓝 |
| E 列 | E=C 且 B≠C | 浅绿 |
| E 列 | 其他 | 浅紫 |
| B/C/D | 三列相等 | 浅红 |
| B/C/D | B=C≠D | 白 |
| B/C/D | B≠C | 浅黄 |
| A 列 | 系别×舰种 | 浅色渐变 |

## 表格展示

- 数据区中文列用微软雅黑，英文/拉丁列用 Arial；`ship.xlsm` 行高 16.3
