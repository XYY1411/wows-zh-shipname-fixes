# 翻译修正流程

## 舰船名称键值格式

- `IDS_P?S????` — 第一个 `?` 为系别，第二个 `?` 为舰种
- `IDS_P?S????_FULL` — 该舰的完整名称（如 `IDS_PASA002_FULL` = 博格（2019-01-23 前））
- `IDS_PCZ...` 为收集品，不属于舰船词条

## 人工翻译步骤

1. 打开 `translations/<版本号>/ship.xlsm`，启用宏（自动配色）
2. 查看 **A 列键值** 与 **B/C/D 列**（zh / zh_sg / en 官方翻译）
3. 在 **E 列「最终翻译」** 填写修正后的译名
   - 空值显示亮红，填完自动变色提示
   - 宏会根据 E 列与 B/C/D 列的关系自动配色（一致/差异一目了然）
4. 保存文件并提交推送

## 跨版本工作流

- 新版本同步后，`generate_tables.py` 自动把旧版本已填写的最终翻译迁移到新版本
- **只需翻译新增舰船**（最终翻译留空的行）
- 版本差异表 `ship_diff.xlsx` 可快速查看新增/修改的舰船

## 配色规则（ship.xlsm 宏）

| 位置 | 规则 | 颜色 |
|---|---|---|
| E 列 | 空值 | 亮红 |
| E 列 | B=C=D=E | 浅红 |
| E 列 | E=B 且 B≠C | 浅蓝 |
| E 列 | E=C 且 B≠C | 浅绿 |
| E 列 | 其他 | 浅紫 |
| B/C/D | 三列相等 | 浅红 |
| B/C/D | B=C≠D | 白 |
| B/C/D | B≠C | 浅黄 |
| A 列 | 按系别×舰种 90 种组合 | 浅色渐变 |
